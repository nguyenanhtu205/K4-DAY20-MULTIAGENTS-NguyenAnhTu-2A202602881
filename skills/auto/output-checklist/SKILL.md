---
name: output-checklist
description: Use to verify that all required files and modifications have been created or updated as specified.
---
- Create a checklist of all required outputs from the task description.
- For each required file, confirm it exists in the correct location.
- For each required modification, confirm it has been made correctly.
- Check that the content of each file meets the specification (e.g., correct headers, data types, formatting).
- Verify that any prohibited changes (like modifying original tests) have not been made.
- Ensure that any required sections (like CHANGELOG entries) are present and correctly formatted.
- Confirm that the output files are in the correct format (e.g., JSON, CSV) and pass any validation checks.
