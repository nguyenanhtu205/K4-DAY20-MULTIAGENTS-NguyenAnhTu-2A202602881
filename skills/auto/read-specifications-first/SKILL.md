---
name: read-specifications-first
description: Use when starting a new task to ensure you understand all requirements, especially the rules, before writing code or making changes.
---
- Read the entire task description carefully.
- Identify and list all explicit rules and requirements.
- Note any constraints on what you can modify (e.g., "original files in tests/ must not be modified").
- List all required outputs (files to create, files to modify, specific content to include).
- Clarify any ambiguous points by checking provided examples or documentation.
- Before writing any code, review the list of rules and outputs to ensure full understanding.
